# Pomodoro Timer

This is a small pomodoro timer used for productivity.

## Workflow when using a Pomodoro Timer
- One 'pomodoro' is a 25 minute *uninterrupted* work session, each followed by a five minute break.
- Every four 'pomodoros,' there is a 25 minute break before the next pomodoro
- This is used to keep maximum productivity during work sessions
